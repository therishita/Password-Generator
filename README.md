# Password Generator

A simple **Python password generator** that creates random passwords based on the user's chosen length.

## Features

* Custom password length
* Includes letters, numbers, and special characters
* Random password generation
* Simple terminal-based program

## How to Run

```bash
python passwordgenerator.py
```

## Tech Used

* Python
* `random`
* `string`
